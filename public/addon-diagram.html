📦 Inventory Tracking
➕ Admin Adds Stock
Admin goes to product → Addons tab
Clicks "Stock" button on addon
Enters adjustment: +50
Reason: Received
✅ Stock Available
inventory_quantity: 50
inventory_policy: deny
hasStock() → true
Customer can add to cart ✅
⚠️ Stock = 0 (deny)
inventory_quantity: 0
inventory_policy: deny
hasStock() → false
API returns 422 error ❌
♾️ Oversell (continue)
inventory_quantity: 0
inventory_policy: continue
hasStock() → always true
Customer can always order ✅
